## 候選設計方向

以下是從觀察提出的工作假設，待後續預覽確認。

| 候選方向 | 對應證據 | 可轉化為工具設計的方式 |
| --- | --- | --- |
| 黑白灰建立結構，亮黃綠建立視覺焦點 | O01、O02、O03 | 先定底色、文字、面板、主操作與目前位置等語意角色，再試色彩比例；選中狀態可依元件使用黑白反轉。 |
| 大小、粗細、正斜字形形成層級 | O04、O07 | 讓展示標題有明確個性，正文與操作標籤保持可讀；實際字體另行選型。 |
| 圓弧與斜切共同形成形狀語言 | O03、O05、O06 | 區分導航膠囊、內容容器、斜邊選中塊與章節標記，不將同一造型套遍所有元件。 |
| 斜向構圖、淡灰大字與細紋作為輔助層 | O04、O05 | 集中於標題區或背景留白；在密集資訊區降低干擾。 |
| 貼紙與編號作為有節制的識別元素 | O07、O08 | 使用產品自身的名稱、真實章節與操作文案，不依靠角色或官方字標。 |

「街頭感」「海報感」「貼紙感」等詞可用來討論方向，但不能代替可執行規則；正式規則仍需交代形狀、比例、層級與使用位置。

## 待驗證項目

- 主站在手機上的導航、字體縮放、章節標記與內容重排。
- 色碼、字體可用性與替代方案、圓角／斜角／間距比例。
- hover、focus、pressed、disabled、loading 等狀態。
- 動效的觸發條件、節奏、曲線、進出方向與減少動效版本；目前未完成錄影分析，不能宣稱「ZZZ 動效固定為某時長或曲線」。
- 遊戲內哪些元素與官網一致、哪些是局部子風格；待使用者補充材料。
- 不含角色圖與官方標誌的實際工具預覽能否維持辨識度。
